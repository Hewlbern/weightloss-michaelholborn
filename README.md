# Mike Holborn · public weight log

Next.js site for [weightloss.michaelholborn.com](https://weightloss.michaelholborn.com): current weight, a food log, progress photos, weekly calorie charts, and a short research note.

Food totals and targets live in `data/site-data.json` (10–23 Sep 2026). Photos are in `public/photos/` by date. The charts page keeps the earlier weight-path note and adds a Weekly tab (average kcal, maintain / cut lines, daily bars, weigh-ins).
